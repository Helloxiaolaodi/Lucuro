# Lucuro - 鹿客司南

Private source repository for **Lucuro - 鹿客司南**, a lightweight local-first browser new tab extension built with Vue 3, Vite, Manifest V3, and webextension-polyfill.

Language: **English** | [简体中文](./README.zh-CN.md) | [Issues](https://github.com/Helloxiaolaodi/Lucuro/issues)

## Quick Start

```bash
npm install
npm run dev
npm run build
```

The production build is written to `dist/`. `stats.html` is generated by `rollup-plugin-visualizer` after each build.

Store upload packages are generated at `D:\YL2026\Vue\lucuro-edge-v0.1.0.zip` for Chrome/Edge and `D:\YL2026\Vue\lucuro-firefox-v0.1.0.zip` for Firefox, with `manifest.json` at the ZIP root.

## Local Installation & Debugging

If you want to run or test **Lucuro** locally from source, follow the steps for your browser below.

### Chrome

1. Open Chrome and enter `chrome://extensions/` in the address bar.
2. Turn on **Developer mode** in the top-right corner.
3. Click **Load unpacked** in the top-left corner.
4. Select the compiled **`dist/`** folder in the file picker.
5. Open a new tab to load and use **Lucuro**.

### Edge

1. Open Edge and enter `edge://extensions/` in the address bar.
2. Turn on the **Developer mode** switch at the bottom of the left sidebar.
3. Click **Load unpacked** at the top.
4. Select the compiled **`dist/`** folder in the file picker.
5. Open a new tab to load and use **Lucuro**.

### Firefox

1. Open Firefox and enter `about:debugging#/runtime/this-firefox` in the address bar.
2. Click **Load Temporary Add-on...** in the top-right corner.
3. In the file picker, enter the `dist/` folder and select **`manifest.json`** (or any file in that directory).
4. Open a new tab to load and use **Lucuro**.

## Features

- New tab dashboard with a tree-style sidebar, search, draggable cards, custom quote, today's notes with a Markdown toolbar, undo/clear, and an auto-hide sidebar
- Toolbar popup for switching the new-tab startup mode between Lucuro and the browser default page; browser default mode opens the native new tab through `tabs.create({})`
- Automatic import of native browser bookmark trees through the built-in `bookmarks` permission
- Mutually exclusive data sources: browser bookmarks or a user-uploaded local JSON file
- Background upload with blur and crop-selection controls, plus a Lucuro logo default avatar
- Browser-native sync through `chrome.storage.sync` with local fallback
- Ko-fi overseas support and WeChat QR domestic support
- Local-first, no account, no analytics, no external sync service

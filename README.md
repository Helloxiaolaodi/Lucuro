# Lucuro - 鹿客司南

Private source repository for **Lucuro - 鹿客司南**, a lightweight local-first browser new tab extension built with Vue 3, Vite, Manifest V3, and webextension-polyfill.

Public product repository: [https://github.com/Helloxiaolaodi/Lucuro](https://github.com/Helloxiaolaodi/Lucuro)

## Quick Start

```bash
npm install
npm run dev
npm run build
```

The production build is written to `dist/`. `stats.html` is generated by `rollup-plugin-visualizer` after each build.

## Features

- New tab dashboard with sidebar categories, search, draggable cards, custom quote, pocket notes, and an auto-hide sidebar
- Toolbar popup with current-page capture and a new-tab takeover toggle
- One-click capture of native browser bookmark trees through the optional `bookmarks` permission
- Browser-native sync through `chrome.storage.sync` with local fallback
- Local background and avatar upload
- Ko-fi overseas support and WeChat QR domestic support
- Local-first, no account, no analytics, no external sync service
